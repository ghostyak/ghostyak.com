**Boxes와 Folder History의 다운로드 링크를 고쳤습니다.** 새 버전을 배포하면서 설치 파일 이름이 바뀌었는데, 홈페이지의 다운로드 버튼은 예전 이름을 가리키고 있었습니다. 그래서 버튼을 누르면 파일 대신 "찾을 수 없음(404)" 오류가 나왔습니다.

지금은 다운로드 버튼을 누르면 GitHub Releases의 최신 설치 파일을 바로 받을 수 있습니다. 설치 파일 이름에 x64·ARM64 같은 지원 환경을 표시하도록 바꾸면서, 다운로드 버튼에도 같은 표시를 넣었습니다.

그동안 다운로드가 되지 않아 불편을 겪으신 분들께 사과드립니다. 링크가 다시 동작하지 않으면 알려 주세요.
