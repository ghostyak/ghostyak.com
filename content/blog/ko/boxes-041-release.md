**Boxes v0.4.1 배포를 시작했습니다.** [지난 글](/ko/blog/boxes-performance-update)에서 예고한 성능 최적화 버전입니다. Boxes 제품 페이지와 GitHub Releases에서 받을 수 있습니다.

## 더 가볍게 설치됩니다

- **WebView2가 필요 없습니다.** 박스는 물론 메뉴, 설정 창, 트레이까지 모두 Windows 기본 기능으로 다시 만들었습니다.
- **관리자 권한 없이 설치됩니다.** 기본 설치는 현재 사용자 계정에만 설치합니다.
- 설치 파일은 Windows 10/11 64비트(x64)용입니다.

## 새로 추가된 기능

### 라이브 박스

폴더 하나의 내용을 그대로 보여 주는 박스입니다. 박스 안의 폴더나 Windows 탐색기의 폴더를 오른쪽 클릭하고 **이 폴더를 라이브 박스로 열기**를 고르세요. Windows 11 탐색기에서는 **더 많은 옵션 표시** 안에 있습니다.

폴더에 파일이 생기거나 지워지면 박스에도 곧바로 반영됩니다. 라이브 박스는 보기 전용이라 박스에서 폴더 안의 파일을 옮기거나 지우지 않습니다.

### 박스별 보기 전환

박스 아래 상태 표시줄의 버튼으로 **자세히·아이콘·큰 아이콘** 보기를 박스마다 고를 수 있습니다. 자세히 보기에서는 수정한 날짜·유형·크기를 함께 보고, 열 머리글을 눌러 정렬할 수 있습니다. 상태 표시줄 왼쪽에는 항목 수가 표시됩니다.

### 업데이트 알림

새 버전이 나오면 Windows 알림과 트레이 메뉴로 알려 드립니다. 자동으로 내려받거나 설치하지는 않습니다.

## 설치할 때 참고하세요

- 설치 파일에 아직 코드 서명이 없어 처음 실행할 때 **Windows의 PC 보호** 경고가 나올 수 있습니다. **추가 정보**를 누른 뒤 **실행**을 선택하세요.
- 이전 버전에서 만든 박스는 처음 실행할 때 자동으로 가져옵니다.
- 사진 뷰어·시계 등 위젯 기능은 v0.4부터 제외되었습니다.

파일·폴더·앱 바로가기를 박스로 정리하는 기능은 지금처럼 개인·회사·업무용 모두 무료입니다. 사용 중 문제가 생기면 Windows와 Boxes 버전, 문제가 발생한 상황을 함께 알려 주세요.
