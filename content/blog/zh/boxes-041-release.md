**Boxes v0.4.1 已开始发布。** 这就是我们在[上一篇文章](/zh/blog/boxes-performance-update)中预告的性能优化版本。你可以在 Boxes 产品页面和 GitHub Releases 下载。

## 安装更轻巧

- **无需 WebView2。** 我们用 Windows 原生功能重新打造了盒子、菜单、设置窗口和托盘。
- **无需管理员权限。** 默认只为当前用户安装。
- 安装程序适用于 64 位（x64）Windows 10/11。

## 新功能

### 实时盒子

实时盒子会按原样显示一个文件夹的内容。在盒子中或 Windows 文件资源管理器中右键单击文件夹，然后选择**将此文件夹作为实时盒子打开**。在 Windows 11 文件资源管理器中，该命令位于**显示更多选项**中。

文件夹中添加或删除文件时，盒子会立即更新。实时盒子仅用于查看，因此 Boxes 不会移动或删除文件夹中的文件。

### 每个盒子单独切换视图

使用盒子底部状态栏中的按钮，可以为每个盒子选择**详细信息、图标或大图标**视图。详细信息视图会显示修改日期、类型和大小，单击列标题即可排序。状态栏左侧会显示项目数量。

### 更新通知

有新版本发布时，Boxes 会通过 Windows 通知和托盘菜单提醒你。它不会自动下载或安装更新。

## 安装须知

- 安装程序暂未进行代码签名，首次运行时可能会出现 **Windows 已保护你的电脑** 警告。请点击**更多信息**，然后点击**仍要运行**。
- 首次运行时会自动导入你在旧版本中创建的盒子。
- 从 v0.4 起，已移除照片查看器、时钟等小组件功能。

用盒子整理文件、文件夹和应用快捷方式的功能，仍然对个人、公司和工作用途全部免费。如果使用中遇到问题，请告诉我们你的 Windows 和 Boxes 版本，以及问题发生时的情况。
