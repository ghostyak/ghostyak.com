**Folder History v0.1.6 is available.** This update makes it easier to distinguish and find folders you visit often or opened recently.

## See how often you visited a folder

The recent visits list now has a **Visits** column. The count increases when you navigate to a folder in File Explorer. Switching to a window that already shows the folder does not add a visit. Existing records start at one visit after the update.

Last visits appear as “now,” minutes ago, hours ago, yesterday, or a date. Relative times refresh every minute while the window is open.

## Find visits from a recent period

Enter `date:30m`, `date:2h`, `date:7d`, or `date:2w` in search to find folders visited within the last 30 minutes, 2 hours, 7 days, or 2 weeks. You can use these with a folder-name search term and the existing date search.

Click a column heading to cycle through **ascending → descending → off**. Turning sorting off returns to the default, most recent visit first. The new Visits column can also be sorted.

Click a watched folder in the left sidebar to show only its history. Click it again to clear the filter. A filled folder icon shows which filter is active.

## Clearer pinned folders and app information

Pinned folders stand out through filled folder icons and colored row backgrounds. Select a row and press **Space** to pin or unpin it.

The About window brings together the version, developer, website, release page, download, issue-reporting, and contact links. We also adjusted the recording-status indicator below the list and the sidebar layout.

Folder History is free for Windows 11 x64. Download the latest installer from the product page.
