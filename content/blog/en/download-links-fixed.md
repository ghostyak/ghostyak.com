**We fixed the download links for Boxes and Folder History.** The new releases changed the installer file names, but the download buttons on our website still pointed to the old names. As a result, clicking a button showed a "Not Found (404)" error instead of a file.

Now the download buttons fetch the latest installer from GitHub Releases directly. The installer names now show the supported platform, such as x64 or ARM64, and the download buttons show the same label.

We apologize to everyone who could not download the apps in the meantime. If a link stops working again, please let us know.
