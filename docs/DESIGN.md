# 디자인 시스템

## 목적과 적용 범위

ghostyak.com의 공개 UI는 Tailwind CSS와 DaisyUI를 기본 디자인 시스템으로 사용한다. Stardock의 제품 중심 정보 구조와 큰 회전형 히어로를 참고하되 GhostYak의 색상, 여백, 문구와 컴포넌트로 독립적인 화면을 구성한다.

## 우선순위

1. 의미에 맞는 DaisyUI 컴포넌트와 상태 클래스를 사용한다.
2. 배치, 간격, 크기와 반응형 처리는 Tailwind CSS 유틸리티로 구성한다.
3. 반복되는 색상은 GhostYak DaisyUI 테마 토큰을 사용한다.
4. DaisyUI와 Tailwind CSS로 표현하기 어려운 동작이나 시각 효과만 최소한의 사용자 정의 CSS로 추가한다.

`src/app/globals.css`에는 Tailwind CSS·DaisyUI 로딩, GhostYak 테마, 기본 접근성 규칙과 회전 화면 진입 애니메이션만 둔다.

## 화면 원칙

- 밝고 차분한 기본 화면과 파란색 `primary` 행동을 유지한다.
- 홈 첫 화면은 이미지와 메시지가 함께 바뀌는 회전형 히어로다.
- Boxes 첫 화면은 제품명, 설명, 무료 다운로드 버튼 하나를 가장 먼저 보여준다.
- 실제 스크린샷 전에는 이미지 안에 교체용 데모임을 명시한다.
- 카드와 그림자는 정보 계층을 구분하는 데 필요한 만큼만 사용한다.
- 블로그는 긴 글을 읽기 좋은 좁은 본문 폭과 명확한 제목 계층을 사용한다.

## DaisyUI 구성

| 용도 | 기본 구성 |
| --- | --- |
| 헤더 | `navbar` |
| 주요 행동 | `btn btn-primary` |
| 보조 행동 | `btn-outline` 또는 텍스트 링크 |
| 제품·글 목록 | `card` |
| 상태와 파일 정보 | `badge` |
| 경로 표시 | `breadcrumbs` |
| 안내 | `alert` |
| 푸터 | `footer` |

## 반응형과 접근성

- 320px부터 가로 스크롤 없이 주요 행동을 사용할 수 있어야 한다.
- 터치 대상은 최소 44×44px 수준을 유지한다.
- 모든 링크와 회전 컨트롤은 키보드로 사용할 수 있어야 한다.
- 회전 영역은 현재 화면을 알리는 이름, 화면 선택 버튼과 재생·정지 버튼을 제공한다.
- 마우스가 올라가거나 키보드 포커스가 들어오면 자동 회전을 잠시 멈춘다.
- `prefers-reduced-motion` 환경에서는 자동 회전과 진입 애니메이션을 사용하지 않는다.
- 색상만으로 현재 상태를 구분하지 않고 ARIA 상태도 함께 제공한다.
- 번역문이 길어져도 제목, 버튼과 메뉴가 잘리거나 겹치지 않아야 한다.
- 고정 너비는 한국어 문장 길이에 맞추지 않고 지원 언어의 긴 문구를 수용해야 한다.
- 언어 선택 메뉴는 현재 언어를 표시하고 대응하는 현재 콘텐츠로 이동해야 한다.

국제화 화면의 문구와 검수 기준은 [INTERNATIONALIZATION.md](./INTERNATIONALIZATION.md)를 따른다.

## Server Component 원칙

DaisyUI 사용만으로 Client Component를 만들지 않는다. 현재 클라이언트 경계는 회전 타이머를 담당하는 `AutoCarousel`과 다운로드 타이머를 담당하는 `DownloadCountdown`이다.
