# 디자인 시스템

## 목적과 적용 범위

ghostyak.com의 공개 UI는 Tailwind CSS와 DaisyUI를 기본 디자인 시스템으로 사용한다. GhostYak의 색상, 여백, 문구와 실제 제품 화면을 사용하며 바탕화면 정리를 중심으로 소개한다.

## 우선순위

1. 의미에 맞는 DaisyUI 컴포넌트와 상태 클래스를 사용한다.
2. 배치, 간격, 크기와 반응형 처리는 Tailwind CSS 유틸리티로 구성한다.
3. 반복되는 색상은 GhostYak DaisyUI 테마 토큰을 사용한다.
4. DaisyUI와 Tailwind CSS로 표현하기 어려운 동작이나 시각 효과만 최소한의 사용자 정의 CSS로 추가한다.

`src/app/globals.css`에는 Tailwind CSS·DaisyUI 로딩, GhostYak 테마, 기본 접근성 규칙과 회전 화면 진입 애니메이션만 둔다.

## 화면 원칙

- 공통 헤더 로고, 기본 파비콘, Open Graph·Twitter 이미지와 구조화 데이터의 발행자 로고는 `public/favicon.svg`를 사용한다.
- 밝고 차분한 기본 화면과 파란색 `primary` 행동을 유지한다.
- 홈은 제품 목록을 제공한다. Boxes 제품 첫 화면은 제품명, 짧은 소개와 무료 다운로드를 중심으로 구성하고 실제 스크린샷을 보여준다.
- 홈의 Boxes 카드와 제품 첫 화면은 사용자 지정 `boxes-screen-01.png`를 원본 비율로 표시한다. 고정 높이와 `object-cover`로 사진·시계·바로가기 영역을 자르지 않는다. 사진 위젯의 확대 설명은 기존 이미지와 크롭을 별도로 유지한다.
- 첫 화면과 설치 안내에서 공식 설치 파일로 바로 내려받는다.
- 실제 스크린샷 전에는 이미지 안에 교체용 데모임을 명시한다.
- 카드와 그림자는 정보 계층을 구분하는 데 필요한 만큼만 사용한다.
- 블로그는 긴 글을 읽기 좋은 좁은 본문 폭과 명확한 제목 계층을 사용한다.

세계시계 미리보기는 첨부 제품 화면을 참고한 HTML 재구성이며 실제 스크린샷 또는 실시간 시계로 표현하지 않는다. 공개 랜딩에서는 서울·런던 두 도시를 두 열로 표시하며 날짜는 현재 로케일로 포맷한다.

## DaisyUI 구성

| 용도 | 기본 구성 |
| --- | --- |
| 헤더 | `navbar` |
| 제품 선택 | `dropdown` · `menu`, 클릭으로 열리는 `details`/`summary` |
| 주요 행동 | `btn btn-primary` |
| 보조 행동 | `btn-outline` 또는 텍스트 링크 |
| 제품·글 목록 | `card` |
| 상태와 파일 정보 | `badge` |
| 경로 표시 | `breadcrumbs` |
| 안내 | `alert` |
| 푸터 | `footer` |

## 반응형과 접근성

- 320px부터 가로 스크롤 없이 주요 행동을 사용할 수 있어야 한다.
- 터치 대상은 최소 44×44px 수준을 유지한다.
- 모든 링크와 회전 컨트롤은 키보드로 사용할 수 있어야 한다.
- 회전 영역은 현재 화면을 알리는 이름, 화면 선택 버튼과 재생·정지 버튼을 제공한다.
- 마우스가 올라가거나 키보드 포커스가 들어오면 자동 회전을 잠시 멈춘다.
- `prefers-reduced-motion` 환경에서는 자동 회전과 진입 애니메이션을 사용하지 않는다.
- 색상만으로 현재 상태를 구분하지 않고 ARIA 상태도 함께 제공한다.
- 번역문이 길어져도 제목, 버튼과 메뉴가 잘리거나 겹치지 않아야 한다.
- 고정 너비는 한국어 문장 길이에 맞추지 않고 지원 언어의 긴 문구를 수용해야 한다.
- 언어 선택 메뉴는 현재 언어를 표시하고 대응하는 현재 콘텐츠로 이동해야 한다.

국제화 화면의 문구와 검수 기준은 [INTERNATIONALIZATION.md](./INTERNATIONALIZATION.md)를 따른다.

## 승인된 바탕화면 정리 중심 랜딩

2026-09-07 승인된 [RENEWAL_KO.md](./RENEWAL_KO.md)의 기능·정책·설치 내용을 제품 소개와 8개 번역 언어에 적용한다. 2026-09-13 사용자 요청에 따라 제품명 중심으로 첫 화면을 간소화했다. 공통 헤더는 모바일 약 56px, 데스크톱 약 64px의 한 줄이며 제품·블로그·언어 선택을 제공한다. Boxes 페이지에서는 데스크톱 공통 헤더에도 무료 다운로드를 제공한다. 홈은 GhostYak 공통 헤더·푸터와 함께 `GHOSTYAK SOFTWARE` 아래 Boxes, Clock과 OSINTS 제품 카드 및 `BLOG` 진입점을 간결하게 제공한다.

- 제품 아이콘과 `Boxes`를 가운데 정렬하고, 제품명을 페이지에서 가장 큰 H1으로 표시한다. 기존 승인된 소개 문구는 작은 한 문장으로 이어 표시한다.
- 첫 화면은 제품명 → 짧은 소개 → 다운로드·설치 안내 → Windows 지원 정보 → 실제 스크린샷 순서다. 긴 소개 문단과 이미지 위의 반복 제목은 표시하지 않는다. 원본 이미지 보기와 언어별 캡션은 유지한다.
- 원본 위치 유지와 사용 방법은 정리 방식에서, 개인·회사·업무용 무료 범위는 무료 정책과 FAQ에서 설명한다.
- 정리 방식 → 시계·사진 위젯 → 무료 정책 → FAQ → 설치 안내 순서다. Fences 대안을 찾는 사용자 안내는 FAQ에서 제공한다.
- 현재 무료 기능에는 디지털 시계·세계시계와 사진 뷰어도 명시한다. 향후 유료화는 짧은 안내로 둔다.
- HTML 정리 방식 설명도와 세계시계에는 예시임을 표시한다. 실제 녹화 영상처럼 재생 버튼을 붙이지 않는다.
- 밝은 기본 화면, 파란색 행동 버튼, 어두운 제품 스크린샷을 사용한다. 새 전역 CSS와 별도 테마는 추가하지 않는다.
- 파란 공통 네비바만 고정한다. 스크린샷 아래의 링크 복사 영역과 네 가지 목차 링크는 표시하지 않는다. 공통 헤더와 제품 본문의 최대 폭을 `max-w-7xl`로 맞춘다. 구역 이동 여백은 단일 헤더 기준으로 둔다.
- FAQ는 DaisyUI `collapse`와 네이티브 `details`/`summary`를 사용한다.
- 설치는 완료 후 자동 실행을 기본 흐름으로 안내한다. WebView2와 수동 실행은 기본적으로 접힌 문제 해결 도움말에 둔다. 사진은 ‘사진 보기·슬라이드쇼’와 실제 박스 메뉴 사용법으로 설명한다.
- 모든 무료 다운로드 버튼은 공식 설치 파일에 직접 연결하고 `설치 안내` 링크만 구역 이동에 사용한다. PC용 링크 복사는 설치 안내에 두며 현재 언어의 제품 URL을 복사한다.

## Server Component 원칙

DaisyUI 사용만으로 Client Component를 만들지 않는다. 공개 랜딩의 클라이언트 경계는 언어 선택을 담당하는 `LanguageSwitcher`, 링크 복사의 `CopySiteLink`, 공통 헤더 제품 메뉴의 `ProductsDropdown`이다. 제품 메뉴는 Boxes, Clock과 OSINTS 링크를 제공하며 바깥 클릭, 포커스 이탈, Escape와 링크 선택 시 닫힌다. FAQ와 실행 도움말은 네이티브 `details`/`summary`다.
