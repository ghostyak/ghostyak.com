# ghostyak.com 로드맵

ghostyak.com은 GhostYak 소프트웨어를 소개하고 배포하는 공식 웹사이트다. 현재는 첫 제품 Boxes와 한국어 콘텐츠를 완성하는 데 집중한다.

- [x] DaisyUI 기반 공통 헤더와 푸터 개편
- [x] 루트 `/`를 한국어 대표 홈페이지로 전환
- [x] 이미지, 문구와 버튼이 자동 회전하는 홈 히어로 구현

- [x] `/product/boxes`에 제품명, 무료 다운로드 버튼 하나와 자동 회전 화면 구현
- [x] 교체 가능한 제품 이미지와 중앙 제품 데이터 추가
