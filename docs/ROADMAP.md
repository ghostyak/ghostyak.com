# ghostyak.com 로드맵

ghostyak.com은 GhostYak 소프트웨어를 소개하고 배포하는 공식 웹사이트다. 현재는 첫 제품 Boxes와 한국어 콘텐츠를 완성하는 데 집중한다.

## 완료: 한국어 사이트 전면 개편

- [x] DaisyUI 기반 공통 헤더와 푸터 개편
- [x] 루트 `/`를 한국어 대표 홈페이지로 전환
- [x] 이미지, 문구와 버튼이 자동 회전하는 홈 히어로 구현
- [x] 홈의 제품 둘러보기 버튼을 `/product/boxes`에 연결
- [x] `/product/boxes`에 제품명, 무료 다운로드 버튼 하나와 자동 회전 화면 구현
- [x] 교체 가능한 제품 이미지와 중앙 제품 데이터 추가
- [x] 무료 설치 파일용 `/product/boxes/download` 경로 유지
- [x] Community/Pro 선택 UI와 공개 Pro 경로 제거
- [x] 기존 제품·언어 주소를 새 대표 경로로 영구 리디렉션
- [x] Markdown + remark/rehype 블로그 구현
- [x] Hello World 글과 sitemap 항목 추가

## 완료: 국제화 기반과 기존 언어 복원

- [x] 한국어 원문 기반 국제화 및 번역 기준 문서화
- [x] 기존 언어 URL을 대응 한국어 콘텐츠로 보내는 임시 fallback 리디렉션
- [x] 기존 8개 번역 언어와 Hello World 블로그 공개
- [x] 한국어 UI 문구를 원문 사전으로 분리
- [x] 지원 로케일 레지스트리와 서버 전용 사전 로더 구현
- [x] 접두사 없는 한국어와 `/{locale}` 번역 경로 구현
- [x] 브라우저 언어 자동 감지와 사용자 선택 쿠키 구현
- [x] 언어 선택 메뉴와 대응 콘텐츠 이동 구현
- [x] 번역 키, placeholder와 블로그 원문 리비전 검사 추가
- [x] 언어별 canonical, `hreflang`, 메타데이터와 sitemap 구현
- [x] 320px 모바일과 데스크톱 언어 메뉴·레이아웃 검수

세부 기준과 언어 추가 완료 조건은 [INTERNATIONALIZATION.md](./INTERNATIONALIZATION.md)를 따른다.
