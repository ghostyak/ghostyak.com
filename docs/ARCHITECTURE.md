# 아키텍처

## 개요

ghostyak.com은 Astro로 빌드하는 정적 웹사이트다. 초기에는 서버, 데이터베이스, 사용자 계정 없이 Boxes 제품 소개와 다운로드 제공에 집중한다.

## 기술 구성

- Astro 7
- TypeScript strict 설정
- Astro 컴포넌트와 HTML/CSS
- npm 패키지 관리
- 정적 파일 배포

React 같은 클라이언트 UI 프레임워크는 상호작용이 꼭 필요한 기능이 생길 때만 추가한다.

## 디렉터리 역할

```text
public/          그대로 배포할 이미지, 아이콘, 다운로드 파일
src/components/ 재사용 가능한 화면 구성 요소
src/data/       제품과 다운로드 정보
src/layouts/    공통 HTML 문서 구조
src/pages/      URL과 대응하는 페이지
docs/           설계, 개발, 로드맵 문서
```

현재 홈페이지는 공통 레이아웃과 헤더·푸터·기능 카드 컴포넌트, 제품 데이터 모듈로 구성한다. 새 구조는 실제 기능이 필요해질 때만 점진적으로 추가한다.

## 설계 원칙

- 기본적으로 정적 HTML을 생성한다.
- 제품 정보는 한곳에서 관리하고 여러 페이지에서 재사용한다.
- 공통 UI만 컴포넌트로 분리하고 작은 마크업은 페이지에 유지한다.
- 이미지와 다운로드 파일은 빌드에 포함할 필요가 없으면 `public`에 둔다.
- 다운로드 파일이 크거나 릴리스가 잦으면 GitHub Releases 같은 외부 저장소를 사용한다.
- 클라이언트 JavaScript는 사용자 경험에 필요한 경우에만 추가한다.

## 목표 페이지

- `/`: ghostyak.com과 Boxes를 소개하는 홈페이지
- `/products/boxes`: Boxes 상세 정보와 다운로드 안내
- `/products`: 제품이 둘 이상일 때 추가할 제품 목록

자세한 구현 순서는 [ROADMAP.md](./ROADMAP.md)를 따른다.
