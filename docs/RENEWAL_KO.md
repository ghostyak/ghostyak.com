# Boxes 리뉴얼 한국어 원문

상태: 2026-09-07 한국어 원문 사용자 승인. 홈·제품 소개와 기존 8개 번역 언어에 공개 적용한다.

## 사용자와 확정한 방향

- 바탕화면 정리를 핵심으로 소개하고 시계·사진 위젯을 추가 장점으로 배치한다.
- Fences의 대안을 찾는 Windows 사용자를 첫 대상으로 삼는다.
- 기본 정리 기능은 개인·회사·업무용 모두 무료다.
- 새로운 위젯과 동기화 기능을 통한 유료화를 계획한다.
- 추가 유료 기능의 범위, 가격과 출시 일정은 확정된 것으로 표현하지 않는다.

## 관리 위치

한국어 원문은 `src/i18n/landing/ko.ts`, 화면은 `src/components/renewal/RenewalLanding.tsx`에서 관리한다. 공개 사전의 `landing` 키로 통합했으며 8개 번역 파일이 같은 구조를 가진다.

## 메시지와 정보 순서

1. **파일은 제자리에, 바탕화면은 내 방식대로.** 파일·폴더·앱 바로가기를 목적별 박스에 모으고 원본 위치를 유지한다. 첫 화면에서 Windows 지원과 회사 사용을 포함한 기본 기능 무료를 안내한다.
2. **저장은 폴더에. 작업은 박스에서.** 기존 폴더의 항목을 작업별 박스에 바로가기로 연결하는 방식을 그림과 세 단계로 설명한다.
3. **Fences 대안이라는 맥락.** 첫 화면과 FAQ에 배치하고, 중복되는 별도 소개 구역은 없앴다. 원본 보존 외에 같은 항목의 여러 박스 연결, 배치 잠금, 모니터별 위치 복원을 설명한다. AlternativeTo의 `/about/` 소개 페이지를 연결한다.
4. **시계·사진 뷰어.** 현재 제공하는 시계·사진도 무료라고 명시한다. 사진은 ‘사진 보기·슬라이드쇼’로 소개하며 박스에 사진이나 폴더를 넣고 `사진 뷰어 → 시작`을 켜는 실제 사용법을 안내한다. 세계시계는 시간 예시를 표시한 HTML 설명이고 사진은 제품 스크린샷의 해당 부분을 보여준다.
5. **무료 정책과 향후 계획.** 기본 정리, 디지털 시계·세계시계, 사진·슬라이드쇼를 하나의 무료 기능 목록으로 정리한다. 새로운 위젯·동기화 유료화 계획은 짧은 각주와 FAQ에 둔다.
6. **FAQ.** 회사 사용, 기존 바탕화면 아이콘 유지·숨김, 원본 보존, Fences 동시 설치 시 더블클릭 설정, Windows/WebView2 요구사항, 동기화의 현재 상태와 피드백 링크를 설명한다.
7. **다운로드·설치 안내.** 모든 무료 다운로드 버튼은 공식 GitHub 설치 파일에 직접 연결한다. 별도 `설치 안내` 링크만 아래 구역으로 이동한다. 기본 흐름은 설치 파일 실행 → 완료 후 자동 실행 → 첫 박스 만들기다. WebView2는 기본 단계에서 제외하고, 기본적으로 접힌 ‘설치 후 실행되지 않나요?’ 도움말에 실행 선택 해제·Runtime 누락 가능성·피드백 링크를 안내한다. 최신 버전은 GitHub Releases 링크로 확인한다.

모바일에서도 정리 방식·위젯·무료 정책·FAQ 네 가지 메뉴를 고정 헤더의 두 번째 행에 표시한다. 모든 이동 대상에 헤더 높이 이상의 스크롤 여백을 둔다. PC에서 열 홈페이지 주소 복사는 첫 화면(태블릿 이하)과 설치 안내에 제공한다.

## 제품 확인 근거와 이미지

2026-09-06에 로컬 앱 개발 저장소 `ghostyak-boxes`의 v0.3.38 (`2fdf3dc`)을 읽기 전용으로 확인했다.

- `docs/monetization.md`, `README.md`: 현재 단일 제품, 계정·결제·평가 기간 없음, 박스·항목 수 제한 없음, 기존 기능을 사후에 임의로 잠그지 않는 정책.
- `README.md`, `src/items/actions.rs`: 오른쪽 버튼 드래그로 박스 생성, 원본 경로 등록, 박스 항목 제거 시 원본 유지, 바탕화면 아이콘 숨김과 Fences 동시 설치 동작.
- `installer/GhostyakBoxes.iss`: x64 호환 설치, 관리자 권한 필요, WebView2 Runtime 포함·자동 설치 단계 없음. Runtime 부재 PC의 설치 실행 테스트를 한 것은 아니다.
- Microsoft의 [WebView2 페이지](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)에서 Evergreen Bootstrapper 별도 설치 안내를 확인했다.

2026-09-07 사용자 피드백 반영: 일반 설치 완료 화면의 실행 항목은 기본 선택되어 있다. Microsoft [배포 문서](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)에 따르면 Windows 11에는 Runtime이 포함되고 대부분의 Windows 10 PC에도 이미 설치되어 있으나 일부 Windows 10 PC에는 없을 수 있다. Runtime 설치를 모든 사용자에게 요구하는 절차로 표현하지 않으며 모든 실행 실패의 원인으로 단정하지 않는다. 사용자는 모니터 배치 복원 관련 검증이 완료되었다고 확인했으므로 추가 미검증 안내는 넣지 않는다.

히어로 이미지는 사용자가 [AlternativeTo에 등록한 제품 스크린샷](https://alternativeto.net/software/ghostyak-boxes/about/)을 가져온 `public/images/renewal/boxes-desktop.webp`다. 원본 제공 URL은 `https://img.alternativeto.net/s/1200x1200/webp/ghostyak-boxes_102969_full.png`이며 1200×653, 41,822바이트다. 이미지 픽셀은 변경하지 않았다. 첫 화면은 전체 이미지와 크게 보기 링크를 제공하고, 사진 카드는 CSS로 사진 뷰어 영역만 보이게 한다. 게임·앱 바로가기 사용 사례이며, 업무 파일 정리 영상으로 설명하지 않는다.

HTML 작업 공간 모형과 `boxes-hero-concept-v3.png`는 리뉴얼 과정에서 제거했다. `src/data/landing.ts`에서 이미지·링크·세계시계 예시 시점을 관리한다.

## 2026-09-06 리뷰 반영 검증

- 320px·390px·768px·1366px 뷰포트에서 가로 넘침이 없고 주요 메뉴가 표시됨을 확인했다.
- 모바일 메뉴 터치 높이는 44px이며 구역 이동 후 제목이 고정 헤더 아래에 표시된다.
- 390px 설정(스크롤바 제외 본문 375px), FAQ 첫 항목만 열린 상태에서 페이지 높이는 7,471px에서 5,617px로 줄었다. FAQ 시작 위치는 5,867px에서 약 3,808px로 줄었다.
- 모든 무료 다운로드 링크의 직접 설치 URL을 확인했고, 설치 파일 HEAD 요청은 200과 3,668,731바이트를 반환했다. 설치 파일은 실행하지 않았다.
- 상단 PC 링크 복사 성공 상태, FAQ Enter 키 열기, 제품 이미지 로딩과 사진 영역 표시를 확인했다.
- 설치 안내 링크는 `#download`로 이동하며 Microsoft WebView2 링크는 접힌 도움말 안의 공식 다운로드 페이지로 연결한다.
- `npm run lint`, `npm run build`를 통과했다. 최종 브라우저 검사에서 오류·경고 로그가 없었다.

## 2026-09-07 공개 적용 검증

- 한국어 및 8개 번역의 홈·제품 경로, 언어별 title/canonical/hreflang/공유 이미지/JSON-LD를 프로덕션 빌드에서 확인했다.
- 320px·768px·1366px에서 9개 언어를 검사하고 프랑스어 다운로드 버튼의 모바일 넘침을 수정했다.
- 언어 메뉴 전환과 Escape 포커스 복원, 설치 안내 앵커 위치, 접힌 WebView2 도움말의 키보드 열기, 실제 이미지 로딩을 확인했다.
- 기존 다운로드 주소는 같은 언어의 홈 설치 안내로 307 이동한다. 공개 본문에는 한국어 fallback이 없다.
- 공개 페이지의 기존 분석 로더는 유지한다. 추가 다운로드 전환 이벤트 계측은 이번 공개 적용 범위에 포함하지 않는다.
